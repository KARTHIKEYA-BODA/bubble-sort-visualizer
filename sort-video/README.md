# 🐧 Bubble Sort Video (Remotion)

This directory contains the source code for the **Bubble Sort 3D Animation Video**.

For full project documentation, visual previews, and demos, please refer to the [Root README](../README.MD).

## Quick Commands

### 1. Type Check
```bash
npx tsc --noEmit
```

### 2. Render Video
```bash
npx remotion render src/index.ts Sort out/sort.mp4
```

### 3. Play Video (Windows)
```cmd
start out\sort.mp4
```

### 4. Interactive Studio Preview
```bash
npm run dev
```
